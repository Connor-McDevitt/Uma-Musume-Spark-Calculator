Optional local portrait library

Place one JPG per Global Uma in this folder, named after the catalog slug:
  special-week.jpg
  silence-suzuka.jpg
  tokai-teio.jpg

The app reads these files locally and never contacts an image host. If a JPG
is not present, the picker displays its built-in monogram illustration.

No third-party character art is included. Only add portraits that you have
permission to use and redistribute with this application.
